# EduSlot / Timetable Management System

> 📚 **Status: Legacy academic project**

A 5th-semester departmental minor project for creating and managing department timetables, importing timetable data and generating clash-free schedules.

## Features

- Create and modify department timetables
- Import timetable data from Excel
- Generate clash-free timetables
- Send teacher notifications through the historical WAY2SMS integration
- Generate timetable PDFs using jsPDF

## Portfolio context

This project is intentionally preserved as an **academic/legacy project**. It demonstrates an earlier stage of my development journey and is not part of my current active engineering roadmap.

My current focus is on **software engineering, enterprise automation, backend/API development, AI systems and cloud technologies**.
